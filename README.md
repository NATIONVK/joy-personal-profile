# JOY — Personal Portfolio

A responsive personal portfolio for **Yeasien Ahmed (Joy)**, built with vanilla HTML, CSS and JavaScript.

## Highlights
- Responsive layout for mobile, tablet and desktop
- Dark visual theme with subtle motion and accessible reduced-motion support
- About, interests, learning journey, projects and contact sections
- Mobile navigation and scroll-reveal interactions
- No build tools or framework required

## Run locally
Open `index.html` in any modern browser.

## Publish with GitHub Pages
This repository includes a GitHub Actions workflow that publishes the site from the repository root whenever changes are pushed to `main`.

If this is the first deployment, open **Settings → Pages** and set **Build and deployment → Source** to **GitHub Actions**. Then check the **Actions** tab for the deployment result.
